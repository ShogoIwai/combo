## 0. 入力一覧

## 1. Situation（前提・共通認識）

各セッションに共通する出発点。全員が所与としていた事実・環境・制約を、解釈を混ぜずに書く。
文末に根拠を `[D1 p.3]` 形式で付ける。

## 2. Complication（何が問題になったか）

Situation のどこが崩れて議論になったのか。痛み・ズレ・制約の顕在化を書く。
セッション間で温度差がある場合はその差自体を書く（例: D1 は納期、D3 は品質を問題視 `[D1 p.4][D3 p.2]`）。

## 3. Question（議論が答えようとした問い）

Complication から立ち上がる中心的な問いを 1 つ、疑問文で書く。従属する問いは箇条書きで最大 3 つ。

## 4. Answer（結論と打ち手）

### 4.1 結論

中心の問いへの答え。合意に至っていない場合は「合意なし」と明記し、選択肢を並べる。

### 4.2 打ち手

| - | ------ | ---- | ------------ | ---- |
| 1 | 〔打ち手〕 | 〔担当〕 | 〔前提・リスク〕 | `[D2 p.5]` |

## 5. 論点マップ

| 論点 | 区分 | 各セッションの立場 | 根拠 |
| ---- | ---- | ------------------ | ---- |
| 〔論点〕 | 合意 | 〔双方の一致点〕 | `[D1 p.2][D2 p.3]` |
| 〔論点〕 | 対立 | D1: 〔立場A〕 / D3: 〔立場B〕 | `[D1 p.4][D3 p.6]` |
| 〔論点〕 | 未決 | 〔保留の理由〕 | `[D2 p.7]` |

区分セルは **合意 / 対立 / 未決 / 対立なし** のいずれか 1 語だけ（説明を混ぜない）。
対立行は根拠に 2 文書以上を引用し、立場欄に両方の doc ID を書く（G6）。
全セッションが実際に一致していて対立が 1 件も無い場合だけ、区分 `対立なし` の行を 1 本置く。

## 6. 根拠引用

対立・未決の各論点について、判断の決め手になった発言を逐語で引く（G7 で原文照合）。

> 「〔文字起こしからの逐語引用〕」 — [D1 p.4]

1 引用ブロック = 1 引用 = 1 citation。引用文は**引用先ページの中に逐語で存在**すること（G7 がページ単位で照合）。8 文字未満の断片は根拠として弱く FAIL になる。

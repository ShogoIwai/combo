# Windows Search: 検索オプション OFF・開発ディレクトリをインデックス対象から除外

## 背景(症状と原因)

- 症状: Word などの保存時に **SearchFilterHost.exe** が動き、保存が体感で非常に遅くなる。開発ディレクトリ配下で特に顕著。
- 原因(推定): 保存直後に **Windows Search のインデックス作成**が走り、SearchFilterHost が内容・プロパティを抽出して
  インデックスを更新する。対象範囲が広い(開発ディレクトリを含む)と負荷が大きい。
- 下の 2 つの対策で解消した実績がある。特に **2) の除外が最重要**。

## 方針

1. 検索関連のオプション(クラウドコンテンツ検索・検索履歴・検索のハイライト等)を **すべて OFF**。
2. 開発ディレクトリとダウンロードフォルダを**インデックス対象から除外**する。

`%USERPROFILE%\Downloads` は常に確認する。開発ディレクトリは環境ごとに違うので、`WINSET_SEARCH_EXCLUDE`
(`;` 区切りの Windows パス。`%USERPROFILE%` 等は展開される)で**追加**する。未指定なら `exclude:dev-dir` が MANUAL(どこかをユーザーに聞く)。

```bash
WINSET_SEARCH_EXCLUDE='%USERPROFILE%\<開発ディレクトリ>' \
  bash <launch-root>/combo/skills/combo-windows-settings/scripts/winsettings.sh status windows-search
```

## 確認項目(check.ps1 の item 名)

| item | 期待値 | 自動確認 |
| ---- | ------ | -------- |
| `search.cloud-msa` / `search.cloud-aad` | クラウド コンテンツの検索(Microsoft アカウント / 職場または学校アカウント)= OFF | 可(HKCU) |
| `search.history` | このデバイスの検索履歴 = OFF | 可 |
| `search.highlights` | 検索のハイライトを表示する = OFF | 可 |
| `exclude:<フォルダ>` | インデックスから除外されている(配下に Include のルールも無い) | 可(インデックスの除外ルールを読み取り) |
| `exclude:dev-dir` | 開発ディレクトリが指定されている | `WINSET_SEARCH_EXCLUDE` 未指定なら MANUAL |

**対象外: セーフサーチ。** 検索ボックスの Web 検索結果(Bing)から成人向けの内容を除くフィルタ(厳しい / 中程度 / オフ)で、
PC 内のファイル検索やインデックス作成(SearchFilterHost の負荷)には関係しない。このグループの目的に効かないので、既定のまま触らない。

## 手順(GUI)

### 1) 検索オプションを OFF

1. 設定(Win + I)→ **プライバシーとセキュリティ** → **検索のアクセス許可**(版により **検索**)
2. このページの検索関連オプションのトグル(クラウド コンテンツの検索・このデバイスの検索履歴・
   検索のハイライトを表示する など)を **すべて OFF**(セーフサーチは対象外。上の「確認項目」の注)

### 2) 開発ディレクトリを検索対象から除外(最重要)

1. 設定 → **プライバシーとセキュリティ** → **Windows の検索**(版により **検索** 内)
2. **除外するフォルダーを追加**(「拡張検索から除外するフォルダー」)で次を追加
   - `%USERPROFILE%\<開発ディレクトリ>`(例: リポジトリを置いているフォルダ)
   - `%USERPROFILE%\Downloads`
3. 旧来の画面なら **Win + R** → `control srchadmin.dll`(インデックスのオプション)→ **変更** でチェックを外してもよい

## コマンドで適用(任意・ユーザーの了承後のみ)

なし(GUI のみ)。インデックスの除外ルールの書き込みは管理者権限が要るため、このスキルからは行わない。

## 注意

- Windows Search サービス(WSearch)自体の停止・無効化はこのグループの対象外(スタートメニュー・Outlook 等の検索が使えなくなる)。
- 除外を追加した直後はインデックスの再構築が走り、しばらく負荷が出ることがある。

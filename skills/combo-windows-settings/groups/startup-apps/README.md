# スタートアップ: Teams / Copilot の自動起動を無効化

## 方針

- サインイン時に自動起動させない。**まず OS 側のスタートアップを止める**(確実)。アプリ側の設定は補助。
- 対象アプリ名は `WINSET_STARTUP_DISABLE`(正規表現。既定 `Teams|Copilot`)で差し替えられる。

## 確認項目(check.ps1 の item 名)

| item | 期待値 | 自動確認 |
| ---- | ------ | -------- |
| `startup:<アプリ名>` | スタートアップ = 無効(該当が無ければ `startup:none`) | 可(Run の値名と起動コマンドの実行ファイル・スタートアップ フォルダ・ストアアプリの StartupTask を読み取り) |
| `teams-app-settings` | Teams アプリ内の「自動起動」「バックグラウンドで開く」= オフ | MANUAL(Teams が入っているとき。未導入なら INFO) |
| `teams-machine-wide-installer` | 入っていない(入っていると再有効化されることがある) | 可(INFO。復活するときだけ対処) |
| `windows-copilot-policy` | OS 統合の Copilot のポリシー状態 | 参考(INFO) |

## 手順(GUI)

### 0. まず最優先: OS 側の自動起動を止める(確実)

- **方法 A(設定)**: Win + I → **アプリ** → **スタートアップ** → 一覧の **Microsoft Teams / Copilot** を **オフ**
  (直接開く: Win + R → `ms-settings:startupapps`)
- **方法 B(タスク マネージャー)**: Ctrl + Shift + Esc → **スタートアップ アプリ** → **Teams / Copilot** を右クリック → **無効化**

### 1. Microsoft Teams

1. **Teams アプリ内の設定(アプリ側)**: Teams → 右上の **プロフィールアイコン**(または「…」)→ **設定** →
   **全般** → **アプリの起動** で次をオフ(表記は版により異なる)
   - サインイン時に自動的に起動(Teams を自動的に起動する)
   - バックグラウンドで開く
2. **OS 側でもオフ**: 上の「0.」を実施
3. **オフにしても復活する場合(組織配布の PC で起こりがち)**: **Teams Machine-Wide Installer** が入っていると
   再度有効化されることがある → 設定 → **アプリ** → **インストールされているアプリ** で
   **Teams Machine-Wide Installer** をアンインストール(権限・組織の方針で可能な場合のみ)

### 2. Copilot(どの Copilot かで分岐)

- **A) 「Microsoft Copilot」アプリとして入っている場合**: 設定 → アプリ → スタートアップ で **Copilot をオフ**
  (またはタスク マネージャー → スタートアップ アプリ → 無効化)。不要ならアンインストール(環境により不可)
- **B) OS 統合の「Windows Copilot」を止めたい場合**: 組織の PC ではグループ ポリシー
  (ユーザーの構成 → 管理用テンプレート → Windows コンポーネント → Windows Copilot →「Windows Copilot をオフにする」)
  で無効化する運用がある。Home エディションではポリシー編集ができない場合があり、版によってはこのポリシー自体が無い。
  組織のポリシーに関わるので、このスキルからは変更しない。

## コマンドで適用(任意・ユーザーの了承後のみ)

なし(GUI のみ)。スタートアップの有効/無効は設定アプリかタスク マネージャーで切り替える。

## 注意

- スタートアップを無効にしても、手で起動すれば普通に使える。Teams の通知はアプリを起動している間だけ届く。
- アンインストール・ポリシー変更は組織の管理者の方針を優先する。

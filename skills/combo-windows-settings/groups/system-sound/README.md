# システムサウンド: サウンド設定を「サウンドなし」にする

## 方針

- Windows のシステムサウンド(通知音・警告音など)をまとめて消す。サウンド設定(スキーム)を **サウンドなし** に統一する。

## 確認項目(check.ps1 の item 名)

| item | 期待値 | 自動確認 |
| ---- | ------ | -------- |
| `sound-scheme` | サウンド設定 = サウンドなし(`.None`) | 可(HKCU のレジストリ読み取り) |
| `event-sounds` | 各イベントに割り当てた音 = 0 件(アラーム/着信のループ音・ログオン/ロック解除音は除く) | 可 |

## 手順(GUI)

1. **Win + R** → `mmsys.cpl` と入力して Enter
2. **サウンド** タブを開く
3. **サウンド設定** を **サウンドなし** にする
4. **OK**(または **適用**)

## コマンドで適用(任意・ユーザーの了承後のみ)

なし(GUI のみ)。レジストリのスキーム名だけを書き換えても各イベントの音は消えないため、必ず上の画面で切り替える。

## 注意

- アプリ独自の通知音(Teams・メールクライアント等)はこの設定の対象外。各アプリの設定で消す。
- 「Windows スタートアップのサウンドを再生する」はスキームとは別のチェックボックス。必要なら同じ画面で外す。
